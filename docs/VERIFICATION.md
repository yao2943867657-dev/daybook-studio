# v0.1 实测记录

日期：2026-10-27。测试环境：Windows、本机 Node.js 24.19.0、Codex 内置 Chromium 浏览器。不是完整手机兼容性认证。

## 已通过

- `npm ci` 对应依赖安装、TypeScript 类型检查和 Vite 生产构建。
- 4 项核心测试：中文长文分页不丢字、标点不单独换行、空日记/emoji、工程字段与边界校验。
- 实际浏览器打开编辑器，原创示例正确显示。
- 切换横屏/竖屏和复古旅行模板，页面可操作。
- 从文件选择器上传 3 秒 H.264/AAC 测试视频，替换默认示例。
- 实际生成并下载 6 秒横屏 MP4，FFprobe 确认为 H.264、1280×720、6 秒；在浏览器播放器播放通过。
- 实际生成并下载开启原声的竖屏 MP4：H.264、720×1280、AAC 48 kHz 双声道，3.008 秒；音量检查确认有非静音原声音轨。
- 405 字测试日记自动分页为 4 页。
- 包含日记和视频的 ZIP 工程备份；修改标题后导入该备份，原标题、405 字正文与视频均恢复。
- 页面更新后自动恢复上次保存内容。
- 默认示例无外部图片、字体和 API 请求，使用本项目原创 SVG。

## 未完成的验证及已知限制

- iPhone Safari、Android Chrome 真机、PWA 安装与断网运行尚未实测。
- 内置浏览器停止本地生产服务后的离线恢复未通过：发现并修复预缓存重复 URL；修复后复测仍出现空白页面。离线功能保留为待验证能力，当前推荐联网使用，不能按完整离线应用验收。
- 附有 PWA manifest、图标、构建资源预缓存与 Service Worker；这些文件存在不等于已完成所有浏览器安装测试。
- Docker Compose 配置已检查；实际 Docker 构建被 Docker Hub 认证服务网络超时阻断，未能完成容器启动验证。
- 1080p、WebM、3 分钟作品、各类 MOV/HEVC、极低内存设备尚未覆盖。
- 纸页卷曲翻页、人物动画、自由裁剪位置、多图拼贴和 AI 功能不属于首版已实现范围。
- 当前动画按行渐显、页间直接切换。标题与批注画面最多两行，工程保留完整输入。

后续测试请记录浏览器版本、输入编码、画面比例、清晰度及导出格式。测试视频为本地程序生成的测试图与正弦音，不随仓库公开分发；私人素材不进入测试报告。
