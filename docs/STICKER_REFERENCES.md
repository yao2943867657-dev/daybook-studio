# 聊天表情与手账贴纸研究

研究日期：2026-10-27。目标是把固定少女头像改成适合日记表达的软萌动物、动作与短句，并让用户在书页旁直接选用。以下是可追溯的国内平台/品牌及官方数据；不同平台和年份不能合并成“今天的全国热榜”。

## 真实参考

- [线条小狗官方微博](https://www.weibo.com/u/7776232700?tabtype=feed)：可核对角色日常、下午茶、宅家、雨天等情境，页面公开持续上架的系列表情。参考的是动作表达与场景组织，不复制其角色轮廓或表情图片。
- [得力集团官方微博发布的纽赛联名消息（新浪展示页，2026-06-17）](https://www.sina.cn/news/detail/5310879597068967.html)：品牌明确发布硬面口袋本、抽拉记事贴等联名文具。说明国内聊天角色与纸质手账装饰的实际交集；没有把其商业联名素材写入开源包。
- [中国玩协 / CLE 中国授权展：肖像 IP 参展概览（2025）](https://www.chinalicensingexpo.com/cn/media_center/detail?id=17603)：收录线条小狗、黄油小熊、小刘鸭、吾皇猫、小熊虫等。用于确认这些是实际持续运营的品牌，而非自行杜撰的流行名单；参展列表不等于销量排名。
- [中国玩协：线条小狗、黄油小熊授权产品与社媒热度（2025）](https://tjpa-china.com/detail?id=37281)：历史报道提到国内平台的讨论热度。该文时间口径属于 2025 年，不当作 2026 年实时统计。
- [LINE 官方 2024 年度贴图回顾](https://www.linecorp.com/pr/news/2024/1205)：线条小狗首次进入原创新榜前五，圆润动物与情境动作具有明确受众。该数据属于台湾 LINE 市场，不能称为中国大陆微信排行。
- [搜狗输入法皮肤表情开放平台](https://open.shouji.sogou.com/)：可核对国内输入法的表情/皮肤分类、设计师及正版合作机制。借鉴“键盘附近选表情”的交互习惯，不使用该站历史案例数字证明当前热度。

第三方图片仅供研究，没有下载、热链或打包。热门 IP 可由用户从其官方渠道获取并在本机导入；“网上能看到”并不意味着可以作为开源素材再分发。

## 本次内置素材

保留原 60 个 ID，旧日记无需迁移贴纸引用。总数增加到 **92 款**：

- 新增 32 款“软糯聊天”：好耶、收到、贴贴、抱抱、摆烂、委屈、晚安、早安、谢谢、爱你、加油、累了、无语、震惊、不气、想你、撒花、喝水、干饭、摸鱼、忙碌、冲鸭、比心、贴一下、呜呜、好滴、开心、我可以、溜了、求抱抱、放空、生日快乐。
- 原 8 种心情替换为猫、兔、狗、白团子和紫色小熊，用耳朵、眼神、泪滴、姿态和道具区分情绪，保留原心情名称与 ID。
- 原猫兔头像重做为全身动作；全套调亮粉、天蓝、嫩绿和淡紫色，保留白色模切边。
- 贴纸是本项目直接编写的原创 SVG，可在书页和视频中清晰缩放，不依赖外部图片、字体下载或第三方 API。

源文件：`src/catalog.ts`。仍使用项目 MIT 许可。`stickerPacks` 提供聊天、心情与手账小物分组，`catalog` / `getSticker` / `prepareCatalog` / `drawSticker` 等原 API 保持兼容。
