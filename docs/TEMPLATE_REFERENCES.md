# 真实手账参考与模板重设计

研究日期：2026-10-27。本轮针对“模板只换颜色、构图区别不大”的反馈，重做本子结构、文字区域、照片区域、装订和纸材层次。只借鉴真实手账的记录方式与物理构造；所有线条、纹理、地图碎片、票根和植物均由本项目原创绘制，未下载或分发品牌模板和用户手账照片。

## 官方参考

- [Hobonichi：How to use the Hobonichi Techo](https://www.1101.com/store/techo/en/howtouse/)：一日记录、照片与信件贴入、按生活内容自由分区。用于手绘框框和私信日记的“日期—正文—批注—心情”层次。
- [Hobonichi Weeks：双页设计](https://www.1101.com/store/techo/en/2026/all_about/weeks/)：左右页承担不同信息功能，方格纸与分区可自由记录。借鉴双页信息分工，未复制其日程表。
- [TRAVELER'S COMPANY：定制笔记本配件](https://www.travelers-company.com/products/customize)：票据、口袋、标题标签、装饰贴、留绳等真实手账拼贴元素。用于复古旅行的牛皮纸、地图碎片、票根与邮戳构图。
- [TRAVELER'S notebook：Regular Size](https://shop.travelerscompanyusa.com/products/travelers-notebook-black)：皮革封面、可插入地图和票据、不同纸张内芯。旅行本与普通点阵本在材质、照片比例和附页结构上分开设计。
- [MIDORI Diary](https://www.midori-japan.co.jp/english/products/diary/)：布面硬壳、可摊平锁线装订、插画与生活记录并存。用于森林标本本的纤维纸、植物边栏和压花层次，也用于奶油日常的插画陪伴感。
- [Filofax Refillable Notebooks](https://filofax.com/collections/notebooks)：可替换纸张、装订与不同主题封面。用于晴蓝活页的中部金属装订环、塑料保护套、格纹胶带与不同纸片叠层。

| 晴蓝活页 | 透明保护套、蓝格纸、金属环 | 撕纸标题、三色手绘衬底、侧边拼贴与批注 | 非对称多图拼贴；格纹与圆点胶带、纸夹 |

每款均支持单图、双图、三图和四图拼贴。多图在同一页形成真实画框组合，不把每张照片机械地分到单独一页。手机采用竖版独立构图；导出调用同一个渲染器。

## 实现接口

`mediaRects(diary)` 返回全部真实画框，`mediaForSlot` 返回对应素材，编辑器/阅读器的点击和视频覆盖层复用同一组坐标。`editRegions` 返回标题、正文、批注、心情的点击区域。文字和媒体仍然可编辑，未把整张手账效果图当背景。
