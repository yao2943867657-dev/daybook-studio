更新：2026-10-27。本轮针对“土、同质化、纸张像平面图形”的反馈，重新生成八张独立的无字手账材质底板。文字、用户照片、视频、心情与贴纸仍在运行时排版，直接编辑与导出共用坐标。背景仅承担真实纸材、书衣、装订与边角拼贴，不含影视人物或预制日记。

以上是视觉参考，不能据此声称某款是国内热度第一。没有抓取或再分发创作者照片、品牌贴纸、商标或用户附件。图片搜索只用于观察材料；公开项目中的底板均由内置 imagegen 按下列原创提示词生成。

## 实现与验证

- `prepareNotebookAssets()` 预读八张本地材质底板；加载失败时保留可用的程序绘图。
- `mediaRects()` / `editRegions()` / `writingStyle()` 是绘图、点击、更换媒体和页内输入的共同坐标来源。
- `render(..., editingField?)` 可隐藏当前输入字段的 Canvas 字，避免文字重影；PNG / MP4 正常绘制全部内容。
- 手机使用单张实体纸页，上下边角保留比例，中间空白纸张延展；媒体、正文与批注重新纵向排版。
- 构建通过；模板/画幅/布局边界和现有存储、分页测试通过。实际浏览器观察顶部四款材质层次与照片排版可见，后续真机与字体兼容仍需测试。
