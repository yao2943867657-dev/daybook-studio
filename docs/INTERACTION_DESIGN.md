# 口袋日记：编辑、模板与刷新交互

更新：2026-10-27。产品名由用户从五个候选中选择“口袋日记”；保留 GitHub 仓库地址、IndexedDB 标识和旧备份格式，改名不会迁移或清空日记。

## 参考

- [Canva：添加和编辑文字](https://www.canva.com/help/add-and-edit-text/)：点选文字进入编辑，点击文本框外结束。本项目按用户要求采用单击进入。
- [Goodnotes：文本工具](https://support.goodnotes.com/hc/en-us/articles/7353727615375-Type-text-with-the-Text-Tool)：纸面文本框操作、点击外部完成，以及文本输入与其他工具的区分。
- [Canva：使用模板](https://www.canva.com/help/use-templates/)与[更换模板](https://www.canva.com/en_in/help/change-template/)：让模板在编辑器的固定入口与独立面板中可发现，不与示例内容混在一起。

借鉴交互方式，不复制这些产品的代码或素材。

## 当前规则

- 单击标题、正文、批注，在原位置输入；其他文本框仍可点击，直接切换。
- 单击纸面空白或其他区域结束输入；表情键盘和编辑工具保留当前输入，方便在光标处插入表情。
- 点击照片/视频框时先结束文字编辑，保留被点击节点直到其操作完成，避免第一下点击被重绘吞掉；视频播放也不会被立即重绘暂停。
- 顶部常驻“模板”，独立面板区分“本子样式”和“照片布局”。选择后应用并收起；点击外部或 Escape 可关闭。
- 心情区在照片组下方预留独立空白；照片、画框白边和心情不贴纸页下沿。横竖屏、八款本子和四种拼贴组合由几何测试覆盖。
- 初次打开或刷新显示加载状态，读取完成后才显示纸面；读取失败提供重试与导入备份，不自动覆盖旧记录。
- 每个标签页用 sessionStorage 记住日记、页码、手动画幅及阅读/编辑模式。正文与素材仍存 IndexedDB；切到后台会尝试刷新保存队列。
- 模板、加载和错误状态沿用应用的轻纸色和绿色工具体系；手机保留可见“模板”文字，其余常用工具使用带可访问名称的图标。

离线恢复、真机安装与所有手机编码器兼容仍按实测记录的限制说明，不因本轮界面改动宣称已解决。
