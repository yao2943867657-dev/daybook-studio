# 口袋日记 · Pocket Diary

翻开某一天，看到完整的日记；想看视频时，再点一下。照片、手写文字、小表情与手账拼贴，收藏每天的生活。

一个本地优先的开源电子日记与手账项目。v0.5 可以直接在书页里写字，在顶部选择模板，在书页旁打开贴纸键盘，按日期翻阅，也能导出图片或视频，保存后发到小红书、朋友圈。基础使用无需账号、个人后端或 AI 密钥。

## 可以做什么

- 本子按实际纸面边界校准照片组中心，白框两侧留白对称，照片与今日心情作为整体在纸页内居中；适配单图、双图、三图与四格。
- 内置贴纸、自定义图片、Unicode 表情都能插入书页文本框，与文字一起排列、分页和保存；点选后可删除、前后移动、移到新光标位置或桌面拖放。图片与视频导出保留行内图案。
- 多篇日记按日期收藏：日历标记已有记录的日期，支持跳到某天、继续写今天和前后翻篇；长日记自动续页。
- 默认显示完整书页，电脑展开双页，窄屏默认单页阅读；可手动切换。视频在页内点击后播放。
- 顶部常驻“模板”入口，阅读时也能挑选本子样式与 1—4 格照片布局；更换模板保留日记和素材。
- 刷新显示加载提示，再恢复当前标签页上次的日记、页码、画幅和阅读/编辑模式；读取失败可重试或导入备份，不把原记录替换为示例。
- 点击标题、正文或批注，直接在原位置输入，自动保存；正文只编辑当前页对应的内容，其他页保留。心情在书页旁选择，不再打开大对话框。
- 8 款本子：晴野方格、奶油烘焙、旅途票根、蓝格透明、森系标本、深夜胶片、透明六环、樱粉线圈。使用原创生成的实物质感底图，区分透明封套、金属活页、布面、纤维纸、撕纸与拼贴；内容与影像仍由程序单独绘制。见 [真实手账研究](docs/TEMPLATE_REFERENCES.md) 和 [底图生成记录](docs/NOTEBOOK_GENERATION.md)。
- 单张主图、双图拼贴、三张旅行记、四格照片墙；照片与视频混排，每个画框可独立点击替换。
- 书页旁的贴纸键盘：聊天表情、最近使用、分类搜索、自定义图片与 8 种动物心情；92 个原创 SVG，包含 32 款带动作和短句的聊天表情。支持在页内拖动、缩放、旋转或移除，研究来源见 [贴纸参考](docs/STICKER_REFERENCES.md)。
- 编辑时输入 `/贴纸`，或按 `Ctrl/⌘ + ;` 打开贴纸键盘；可以粘贴剪贴板图片作为贴纸，也能在光标处输入 Unicode 表情，与文字一起保存。
- PNG、MP4 或 WebM 导出，9:16 手机竖屏 / 16:9 展开双页，可选择保留原声；支持系统文件分享的设备可调用分享菜单。
- IndexedDB 自动保存每篇日记；单篇与整本 ZIP 备份、恢复；旧版单篇自动迁移，导入保留已有日记。
- PWA 安装配置与离线缓存机制；静态站点、GitHub Pages 和 Docker 部署。

桌面翻页有半页过渡，视频导出使用逐句入页和直接换页。纸张卷曲的物理翻页、人物口型、自由移动所有文字/照片、应用内 AI 生图和原生安装包尚未实现。内置底图已在开发时生成，使用者无需调用生图服务。手机真机兼容性与离线能力仍需验证，具体测试结论见 [实测记录](docs/VERIFICATION.md)。

## 快速开始

需要 Node.js 24，首次安装需要联网。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:8798>。Windows 也可双击项目中的 `启动口袋日记.bat`，终端窗口需保持打开。

1. 点击“写今天”新建或继续当天日记；也可打开“日历与日记”选择其他日期。
2. 直接点击书页文字，在对应位置输入；正文编辑保留其他页，内容自动保存。点击画框上传或替换照片、视频。
3. 用书页旁的贴纸键盘搜索聊天表情、选择心情或上传自己的图片；可以直接粘贴图片，或用 `/贴纸`、`Ctrl/⌘ + ;` 唤出键盘。选择“插入文字中”或“贴在书页上”。书页贴纸可直接点选和拖动，旁边操作条提供删除和缩放。
4. 用顶部“模板”更换本子或选择 1—4 格照片布局；“编辑这篇”提供完整素材、文字和播放设置。点击纸面空白结束输入，点击另一文本框直接继续编辑。
5. 用前后页按钮翻阅。画面默认静止完整呈现，想看页内视频时点击播放。
6. 点击“导出 / 分享”，选择画幅和 PNG / 视频。视频包含当前这篇的全部页，暂不汇编整本日记。

日历面板提供“备份这篇”“备份整本”和“导入日记”。ZIP 包包含日记、排版设置、贴纸与原始素材；导入遇到相同记录编号时会生成副本，不覆盖原有日记。v0.1 的单篇工程包仍可读取，旧版浏览器里的单篇数据会自动迁移；升级若被其他旧标签阻塞，请关闭旧日记页面后刷新。

日记保存在当前浏览器，**清理浏览器数据会丢失本地日记本**。不同网址、端口、浏览器与设备的存储互相独立，换设备或部署地址前先备份，不会自动云同步。

## 导出到小红书 / 朋友圈

“导出 / 分享”中选择 **9:16 竖屏** 或 **16:9 横屏**，再生成视频。导出完成后先在内置播放器查看；可保存文件，或在设备支持时使用系统分享菜单。

本项目不会登录或自动发布到社交平台。系统分享不可用或菜单里没有目标应用时，先保存视频，再到小红书或微信相册选择该视频发布。平台最终接受的时长、画幅和文件格式，以发布时的实际要求为准。

## 部署

### 静态站点

```sh
npm run build
npm run preview
```

将 `dist/` 发布到任意支持 HTTPS 的静态托管。资源使用相对路径，可部署到子目录。构建脚本会把视频导出模块一并加入离线缓存。

### GitHub Pages

仓库 Settings → Pages → Source 选择 **GitHub Actions**。在 Actions 手动运行 **Publish GitHub Pages**。项目附带 CI 编译与核心逻辑测试。

### Docker

```sh
docker compose up --build -d
```

打开 <http://localhost:8798>。容器只提供静态页面，不接收日记数据；数据仍保存在访问者的浏览器里。Docker 配置已提供，但此前本机拉取基础镜像时遇到 Docker Hub 网络超时，容器启动尚未完成实测。

### 手机使用与安装

推荐访问 HTTPS 部署地址。Android 在浏览器菜单选择安装；iPhone 用 Safari 的分享菜单选择“添加到主屏幕”。这些是安装操作指引，尚不代表已经完成真机安装认证。请保持联网使用：项目包含离线缓存实现，但内置浏览器断开本地服务后的恢复测试尚未通过。手机浏览器的视频解码、编码、文件保存与系统分享也需要逐设备验证。

开发时要在局域网手机试用，可运行：

```sh
npm run dev -- --host 0.0.0.0
```

手机访问 `http://电脑的局域网IP:8798`，需要电脑防火墙允许。HTTP 局域网地址可能不具备 PWA 安装和视频编码所需的安全上下文；正式体验请使用 HTTPS。手机上的 `127.0.0.1` 指手机自己。

## 素材与导出限制

| 项目 | v0.5 支持与边界 |
|---|---|
| 图片 | JPG、PNG、WebP、GIF（GIF 导出为静态画面） |
| 视频 | MP4、WebM、MOV 容器，实际解码取决于设备，优先 H.264/AAC MP4 |
| 素材数量 | 每篇最多 20 份照片/视频；另外最多 100 张自定义图片贴纸；单份不超过 200 MB |
| 日记长度 | 每篇最多 10000 字，自动续页 |
| 手绘与心情 | 92 个原创 SVG（含 32 款聊天表情）、8 种动物心情；每篇最多放置 100 个贴纸 |
| 直接输入 | 标题、正文、批注原位编辑；Unicode 表情和图片贴纸均支持行内排列，也可独立贴在书页上；每篇最多 1000 种行内贴纸 |
| 页面影像 | 单图 / 双图 / 三图 / 四格，可混合照片与视频 |
| 图片输出 | 当前页 PNG，横屏 1600×900、竖屏 900×1600 |
| 视频输出 | 当前这篇的全部页、24 fps、720p / 1080p，最长 3 分钟 |
| 视频时长 | 每页 3 / 6 / 9 / 12 秒；片段从开头播放，结束后停在最后一帧 |
| 原声 | 用户勾选时使用每页第一个视频的原声；多视频不混音、不循环、不添加背景音乐 |
| 工程备份 | 单篇/整本 ZIP，素材总计最多 400 MB；导入包最大 420 MB、解压总量最大 450 MB；整本备份最多 5000 篇 |

导出前实际检测 H.264/VP9 和 AAC/Opus 编码能力。设备不支持时给出提示，可尝试 WebM、720p 或新版 Chrome / Edge。不能保证所有 iPhone/Android 型号都能导出视频。导出时保持页面前台，避免锁屏。

当前导出使用主线程分批处理，并定期让出界面事件循环；使用帧级背压，但输出文件与单页音频仍占用内存。Worker、流式文件保存和原生编码是后续优化方向。低内存手机请先用 720p 短作品。

标题超过两行、批注超过两行时，画面只展示前两行，完整文字保留在工程中。字体使用设备自带楷体或衬线体，不同系统外观会略有差异。

## 隐私与开源

素材读取、排版、编码都在当前设备进行，没有上传 API、分析 SDK、远程字体、广告或登录流程。PWA 的更新会下载程序文件。请自行保管导出的视频与工程包。

代码为 MIT，92 个原创手绘 SVG、原创模板绘图、示例插画和应用图标也以 MIT 提供。`public/notebooks/` 的无文字实物质感底图由本项目使用内置 imagegen 生成，随项目提供使用与再分发；提示词与素材记录见 [底图生成记录](docs/NOTEBOOK_GENERATION.md)。Mediabunny 为 MPL-2.0，fflate 为 MIT，见 [第三方说明](THIRD_PARTY_NOTICES.md)。本项目不包含商业模板、影视片段、第三方商业表情包或他人的日记。用户上传的照片、视频、表情和贴纸仍由用户自行确认使用与分享权限。

设计与流程研究参考 [Canva](https://www.canva.com/create/scrapbooks/)、[时光手帐](https://www.shouzhang.com/)、[1 Second Everyday](https://1se.co/)、[StoryPad](https://github.com/theachoem/storypad) 和 [Memos](https://github.com/usememos/memos)，未复制这些项目的代码或素材。
